 # data-analysis-portfolio

R, SQL, Python을 활용한 데이터 분석 포트폴리오 저장소입니다.

## 저장소 소개

이 저장소는 데이터 전처리, 통계 분석, 모델링, 해석 과정을 포함한  
데이터 분석 프로젝트들을 정리하고 포트폴리오 형태로 기록하기 위해 만들었습니다.

각 프로젝트는 개별 폴더 안에 코드, 결과물, 설명 문서 형태로 정리되어 있습니다.

---

## 사용 기술

- SQL
- Python
- R

---

## 프로젝트 목록

### 1. 소비 패턴 전이 분석
**경로:** `projects/consumer-pattern-transition/`

서울 상권 카드 매출 데이터를 활용하여  
소비 구조의 변화(전이)가 다음 분기 위험 신호로 작동하는지를 분석한 프로젝트입니다.

### 주요 구성
- SQL 데이터 파이프라인
- Python 기반 모델링 및 전이 분석
- R 기반 통계 검정
- 발표용 PDF 결과물
