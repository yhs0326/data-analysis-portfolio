# 소비 패턴 전이 분석

서울 상권 카드 매출 데이터를 활용하여  
**소비 패턴의 변화(전이)가 다음 분기 위험 신호로 작동하는지**를 분석한 프로젝트입니다.

---

## 프로젝트 개요

이 프로젝트는 상권·업종 단위의 분기별 카드 매출 데이터를 기반으로  
시간대별 소비 구조를 유형화하고,  
**소비 패턴 전이(cluster shift)** 와 **위험 발생 간의 관계**를 분석하는 것을 목표로 합니다.

핵심 질문은 다음과 같습니다.

> 소비 패턴 전이는 다음 분기 상권 리스크의 선행 신호인가?

---

## 데이터

- 서울 열린데이터광장 카드 매출 분기 데이터 
- 분석 단위: 상권 × 업종 × 분기
- 주요 입력 변수:
  - 시간대별 매출 비중
    - `ts_0_6`
    - `ts_6_11`
    - `ts_11_14`
    - `ts_14_17`
    - `ts_17_21`
    - `ts_21_24`
  - `share_wkend`
  - `pk_shift`

---

## 분석 흐름

### 1. SQL
- 원천 데이터를 상권·업종·분기 단위로 정리
- 시간대별 매출 비중 변수 생성
- 패널 구조 데이터셋 구성
- 전이 분석에 필요한 기초 테이블 생성

### 2. Python
- Logistic Regression 기반 위험 예측
- Walk-forward 방식의 시계열 평가
- K-means 기반 소비 패턴 군집화
- 군집 전이 변수(`cl_cluster_shift`) 생성
- 전이 행렬 및 히트맵 생성
- 코호트 분석용 데이터셋 export

### 3. R
- 전이/유지 집단 간 통계 비교
- 피크 비중 변화량 기반 검정 수행
- 전이 집단과 유지 집단 간 차이 검증

---

## 주요 분석 내용

### 소비 패턴 유형화
시간대별 매출 비중과 주말 비중을 활용하여  
상권의 소비 구조를 군집화하였습니다.

분석 결과 소비 패턴은 다음과 같은 유형으로 구분되었습니다.

- 오전 중심형
- 주말·퇴근 집중형
- 야간 중심형 
---

### 소비 패턴 전이 분석
각 상권·업종의 분기별 군집 변화를 추적하여  
이전 분기와 다른 군집으로 이동한 경우를 **전이(cluster shift)** 로 정의하였습니다.

이를 바탕으로:
- 전이 여부 생성
- 전이 방향 분석
- 전이 이후 위험 발생률 비교
를 수행하였습니다.

---

## 주요 결과

- 소비 패턴 전이 발생 시  
  **다음 분기 위험 발생률이 유지 집단보다 높게 나타남** 
- 발표 결과 기준,  
  **전이 발생 시 위험이 약 1.8배 증가**하는 것으로 나타났습니다. 
- 전이는 무작위가 아니라  
  **특정 방향성을 가진 이동 패턴**을 보였습니다. 
- 전이 이후에도 위험 수준이 일정 기간 지속되는 패턴이 확인되었습니다.
