# Data Notice

원본 데이터는 제공처 이용 조건상 저장소에 포함하지 않았습니다.

프로젝트는 서울시 상권 관련 분기별 데이터를 기반으로 상권의 소비 패턴 변화, 군집 전이, 위험 신호를 분석했습니다.

## Data Used

프로젝트는 서울시 상권 단위의 분기별 매출 데이터를 사용했습니다.

원자료는 2021년부터 2025년까지의 연도별 CSV 파일로 구성되어 있으며, 각 파일은 상권, 업종, 분기별 매출 정보를 포함합니다.

## Data Availability

원자료 및 중간 처리 데이터는 라이선스와 제공처 이용 조건을 고려하여 GitHub 저장소에 포함하지 않았습니다.

따라서 이 저장소의 data폴더는 실제 데이터 파일을 보관하기 위한 폴더가 아니라, 분석에 사용한 데이터의 성격과 비공개 사유를 설명하기 위한 안내용 폴더입니다.
