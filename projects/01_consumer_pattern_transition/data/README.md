# Data Notice

원본 데이터는 제공처 이용 조건상 저장소에 포함하지 않았습니다.

본 프로젝트는 서울 열린데이터광장 카드매출 분기 데이터를 기반으로 상권·업종별 소비 패턴 변화, 군집 전이, 다음 분기 위험 신호를 분석했습니다.

## Data Source

- 데이터명: 서울 카드매출 분기 데이터
- 제공기관: 서울 열린데이터광장
- 사용 기간: 2021Q1 ~ 2025Q2
- 분석 단위: 서울 상권 × 업종 × 분기
- 주요 변수: 상권, 업종, 분기, 시간대별 매출, 주말 매출, 피크 시간대, 소비 패턴 군집, 전이 여부, 다음 분기 위험 여부

## Folder Structure

```text
data/
├── README.md
├── raw/
├── processed/
└── external/
```

| 폴더 | 용도 |
|---|---|
| `raw/` | 원본 데이터 배치 위치 |
| `processed/` | 전처리 후 생성된 분석용 데이터 배치 위치 |
| `external/` | 필요 시 외부 보조 데이터 배치 위치 |

## How to Reproduce

데이터 접근 권한이 있는 경우, 원본 데이터를 아래 경로에 배치한 뒤 코드를 실행할 수 있습니다.

```text
data/raw/
```

전처리 이후 생성되는 분석용 데이터는 아래 경로를 기준으로 저장됩니다.

```text
data/processed/
```
